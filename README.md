# Student Performance Analysis System

This project is a student performance tracking and analysis application developed using Python.  
It allows users to add students, enter grades, and perform statistical analysis on the data.

---

## Features

- Add students  
- Add grades (validation between 0–100)  
- List students and grades  
- Detailed analysis:
  - Average (NumPy)
  - Highest and lowest grade
  - Standard deviation
- Pass / fail determination  
- Identify the top-performing student  
- Calculate class average  
- Delete students  
- Persistent data storage using JSON  
- Visualization of student averages using charts (Matplotlib)  

---

## Technologies Used

- Python  
- NumPy  
- Matplotlib  
- JSON  

---

## Sample Output

Ali -> Average: 75.0 | Highest: 90 | Lowest: 60 | Std: 12.24 | Status: Passed  


# Öğrenci Performans Analiz Sistemi

Bu proje, Python kullanılarak geliştirilmiş bir öğrenci performans takip ve analiz uygulamasıdır.  
Kullanıcıların öğrenci eklemesine, not girmesine ve bu veriler üzerinden istatistiksel analiz yapmasına olanak sağlar.

---

## Özellikler

- Öğrenci ekleme  
- Not ekleme (0–100 aralığında doğrulama)  
- Öğrenci ve not listeleme  
- Detaylı analiz:
  - Ortalama (NumPy)
  - En yüksek ve en düşük not
  - Standart sapma
- Geçti / kaldı durumu belirleme  
- En başarılı öğrenciyi bulma  
- Sınıf ortalaması hesaplama  
- Öğrenci silme  
- Verilerin JSON dosyasında kalıcı olarak saklanması  
- Öğrenci ortalamalarının grafik ile görselleştirilmesi (Matplotlib)  

---

## Kullanılan Teknolojiler

- Python  
- NumPy  
- Matplotlib  
- JSON  

---
